# rfp-review

작성 중인 제안요청서를 검토 지침(체크리스트 등)에 맞춰 점검하고, 고칠 곳에 형광펜과 메모를 단 한/글 파일을 돌려주는 Agent Skill입니다. AI 1차 검토이며, 최종 판단은 담당자가 합니다.

## 설치

```bash
# Claude Code
git clone https://github.com/sj00c/rfp-review ~/.claude/skills/rfp-review
# Codex CLI
git clone https://github.com/sj00c/rfp-review ~/.codex/skills/rfp-review
```

Python 3.10 이상이 필요합니다. PDF 지침을 쓰려면 `pip install pypdf`도 설치하세요.

## 사용

제안요청서와 지침 파일을 주고 "검토해 줘"라고 요청합니다.

- **제안요청서:** `.hwpx` 또는 `.hwp` 1개. `.hwp`는 Windows에 한/글이 있으면 자동으로 변환하고, 없으면 한/글에서 HWPX로 저장해 주세요.
- **지침:** 엑셀, 한글, 워드, PDF, 텍스트 파일. 여러 개 줘도 됩니다.
- **관련 문서(선택):** 공고문, 원가계산서 등. 제안요청서와 내용이 맞는지 대조합니다.

## 결과

제안요청서와 같은 폴더에 `<원본 이름>_검토메모.hwpx`로 저장됩니다. 원본은 고치지 않고, 같은 이름이 있으면 `_2`, `_3`을 붙여 새로 저장합니다.

| 메모 색 | 뜻 |
|---|---|
| 빨강 | 필수수정: 참가자격·배점·금액·제출 방법 등 꼭 고쳐야 할 곳 |
| 노랑 | 수정필요: 오타·번호·문구 같은 그 밖의 오류 |
| 파랑 | 확인필요: 문서만으로 판단할 수 없어 작성자 확인이 필요한 곳 |

첫 문단에는 고칠 곳만 5줄 이내로 추린 요약 메모가 달립니다.
